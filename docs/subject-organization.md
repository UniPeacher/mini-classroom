# 学科、课程与教学预设

## 四层结构

```
学科大类（选择教学预设）
  专业课程（继承所属大类的预设）
    学习主题（学习目标、图谱、摸底和优先级）
      知识点（学习进度、作答与复习调度）
```

例如：大类「理工科」使用「理工科」教学预设，下面有「液压传动」「数字信号处理」两门课程；「液压传动」下可以放多个较小的学习主题。

**教学预设不是分类名。** 用户可以自定义大类名称；多个大类也可以使用同一个预设。课程不再单独覆盖预设，避免多层优先级。

## 从哪里操作

- **学科与课程**：管理大类、课程和主题归属，查看主题数量、学习进度和到期复习。
- **主题页**：调整当前主题所属课程，不改变其已有学习记录。
- **今天**：先选择不限范围、某个大类或某门课程，查看下一节的预览，再开始新课堂。
- **个性化／提示词**：编辑共用表达规则、浏览九套预设原文、查看某门课程实际生效的教学引导词。

未归类主题不会被删除，仍可以在不限范围下学习。

## 提示词如何生效

教学引导词由共用表达规则和大类选定的学科要求组成。课程详情给出配置来源和合并后的预览。该预览是教学引导词，不包含每次任务的知识点、题目结构及全部系统约束。

预设影响讲法、例子、练习语境等教学要求。它不会改变判分标准、数据结构或间隔复习算法，也不会给软件凭空增加听力、语音识别或教材解析能力。

查看预设不等于选择预设。仅保存配置才会生效；涉及尚未开始内容更新时，界面先展示影响范围。已经学过的内容和正在进行的课堂不会被改写。

## 学习范围与未完成课堂

课程范围对新课堂中的新学、复习、抽查和重讲一起生效。范围外的到期复习不会混进来，也不会被标记为已经复习，只会等待你再次学习对应范围。

未完成课堂独立显示原范围。选择新的范围不会偷偷替换它；继续旧课堂和结束旧课堂、开始新课堂是两个明确的操作。新课堂生成失败时，旧课堂应仍可恢复。

## 旧配置迁移

旧分组迁移为大类，旧标签迁移为课程，已有主题关联到对应课程。旧版独立风格覆盖如与大类不一致，会通过明确标识的待整理大类保留其生效方式，并生成迁移报告。

迁移保留原始配置快照，不删除作答、记忆卡片、历史课堂和原始 Markdown，也不重新生成知识图谱。升级时不要手工修改已经提交的迁移文件。

## 备份与回滚

升级前关闭微课堂并备份完整 `data/` 目录；如果存在 SQLite 的 `-wal` 和 `-shm` 文件，也要一起保留。同时备份 `resources/app.asar` 与 `app.asar.unpacked`。

数据库升级后的可靠回滚方式是：关闭新版，恢复成对的旧程序与升级前数据备份。不要只替换旧程序、继续打开已经升级的数据。
