# 学科与课程重构验收清单

验收使用隔离的内存数据库和假模型，不接入真实学习数据或付费模型。运行方式见 development.md。

## 1. 组织管理

- [ ] 侧栏可直接打开「学科与课程」，无需从提示词页寻找。
- [ ] 尚无大类/课程时有清楚的空状态；未归类主题仍能找到。
- [ ] 创建理工科大类，选择理工科预设，保存后列表与详情一致。
- [ ] 创建液压传动、数字信号处理两门课程并归入大类。
- [ ] 将一个或多个已有主题归入课程，首页、导航、管理页显示同一归属。
- [ ] 改名后 ID 和关联不变；重复名称显示错误并保留输入。
- [ ] 移动课程前显示受影响课程、主题和待备内容数量。
- [ ] 删除非空大类/课程被拒绝；不会连带删除学习主题或记录。
- [ ] 保存失败保留草稿；离开未保存编辑有留在此页/放弃修改的明确选择。
- [ ] 从大类详情切到其他大类或课程，不应悄悄丢失尚未保存的草稿。

## 2. 教学要求

- [ ] 九套预设都可浏览，浏览不改保存配置、不发起内容生成。
- [ ] 提示词页将共用规则与学科要求分开标注。
- [ ] 选一门具体课程，预览显示课程、大类、预设来源和合并后的教程/配图引导词。
- [ ] 预览使用服务端同一解析器，不由界面根据最后点击的按钮猜测。
- [ ] 默认/未归类预览清楚说明没有学科追加要求。
- [ ] 改大类预设只影响其课程待备内容，不改历史讲解、记忆阶段或正在进行的课堂。
- [ ] 生成期间归属或配置发生变化，旧结果不作为当前配置内容入池。

## 3. 学习范围

- [ ] 今天页可选不限范围、一个大类或一门课程。
- [ ] 预览所列主题均属于选择的范围，范围外到期内容另行提示。
- [ ] 开课与预览使用同一范围；范围外内容不会混进课堂。
- [ ] 从学习页返回，范围选择仍保留。
- [ ] 未完成课堂显示其原范围，继续与开始新课堂是两个不同动作。
- [ ] 切范围不会隐式结束或替换旧课堂。
- [ ] 新课堂无法生成或准备失败时，旧课堂仍可恢复。
- [ ] 联结题不会随意取无关课程的已知知识作为伙伴。

## 4. 数据与基础功能

- [ ] 迁移保存原始配置快照、冲突/兼容来源说明，并且可重复启动。
- [ ] 主题、知识点、作答、卡片、历史课堂及原始 Markdown 未丢失。
- [ ] 迁移本身不新增模型任务、不改变候选状态。
- [ ] 设置部分更新不清空其他字段；异常旧字段不使全部设置恢复默认。
- [ ] `$...$` 行内与 `$$...$$` 块级公式继续渲染。
- [ ] 复习调度、摸底、历史回看和数据库导入测试通过。
- [ ] 桌面安装包隔离启动、重启持久化、退出停止服务通过。

## 5. 本机部署

- [ ] 先通过集成测试、构建和界面验收，再更新安装包。
- [ ] 检查微课堂已正常退出；不强制结束用户进程。
- [ ] 完整备份 app.asar、app.asar.unpacked、data/（含存在的 WAL/SHM）。
- [ ] 保留校验清单与回滚位置。
- [ ] 未推送远端、未创建 PR、未擅自提交。
