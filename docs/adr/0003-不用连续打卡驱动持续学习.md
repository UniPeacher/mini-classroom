# 不用连续打卡驱动持续学习

原始需求要求"让用户上瘾、持续学下去"。我们不设连续打卡、断签惩罚之类的机制，而是靠两件事：固定的提醒时段形成情境线索，让学习成为习惯；认知地图随真实掌握程度点亮、生长，带来内驱力。漏掉的时段不补、不惩罚，到期内容顺延到下一节。理由是：连胜和断签奖励的是"每天打开"这个动作，而不是真实掌握；断签带来的焦虑还容易让人在中断一次后整体放弃。这和系统"学会、能用、不忘"的目标相悖。

## Considered Options

- 连续打卡、积分排行：短期留存效果明显，但激励对象错了，中断后的放弃风险也高。
- 按到期情况提醒：提醒时刻不可预测，形不成习惯线索，更像打扰。
