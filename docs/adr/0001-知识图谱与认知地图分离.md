# 知识图谱与认知地图分离，联结由用户在练习中亲手建立

知识以两套结构管理：知识图谱是客观、唯一、与用户无关的知识点及其组成/前置/易混关系；认知地图是每个用户的主观结构，引用知识点但不复制它，并可挂靠学习主题之外的已有知识。认知地图上的联结不由系统自动生成、也不开放自由编辑，而是把"说明两个知识之间的关系"做成一种练习，经 AI 批改认可后才成为联结——利用生成效应让地图本身成为记忆的一部分，错误联结触发复习而不入图。每个用户只有一张认知地图，覆盖所有学习主题，因此联结和已有知识可以跨主题挂靠。

## Considered Options

- 认知地图 = 知识图谱 + 掌握度着色：实现最简单，但地图失去"个人认知"的意义，也无法表达已有知识与成长路径。
- 用户自由编辑认知地图：成本高、多数人不会主动整理，且无法保证联结的正确性。
